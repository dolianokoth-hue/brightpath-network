# BrightPath Office Network
This project is a small office network built in Cisco Packet Tracer, one stage at a time. I am using it to practice network engineering skills and document each stage as I finish it.

## Progress
- [x] [Stage 1: Basic LAN] (stage1-basic-lan/)
- [ ] Stage 2: VLANs and trunking
- [ ] stage 3: Inter-VLAN routing
- [ ] stage 4: DHCP and DNS
- [ ] stage 5: Security
- [ ] stage 6: WAN, NAT and branch office
      
## Tools
Cisco Packet Tracer
